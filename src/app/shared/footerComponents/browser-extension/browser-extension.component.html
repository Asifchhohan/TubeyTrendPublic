Browser Extension

Install the TubeyTrend extension to get quick trending topics, title suggestions, and thumbnail previews while browsing YouTube.

  • Contextual trending topics for the current page
  • One-click title and thumbnail suggestions
  • Preview thumbnails at common aspect ratios

Quick start

  1. Install the extension
  2. Open any YouTube video or channel
  3. Click the TubeyTrend icon to view title suggestions and trending topics
