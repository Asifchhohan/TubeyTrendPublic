Browser Extension

The TubeyTrend browser extension gives quick access to trending keyword data and video insights while browsing YouTube.

Features

  • See trending tags and keywords on any video page
  • Quick thumbnail and title suggestions
  • One-click export to TubeyTrend tools

Install & Usage

  1. Install the extension from the Chrome Web Store (or the provided link).
  2. Open a YouTube video and click the extension to view extra insights.
  3. Use quick actions to export ideas or open the app for deeper analysis.

Get started

Click Install or Request Access to receive the extension link.
